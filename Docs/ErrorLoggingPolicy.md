# הגדרות רישום שגיאות במערכת הדוחות

## רמות חומרה וסיווג

### Information (לא נרשם ל-DB)
- הודעות כלליות על התקדמות התהליך
- הצלחות בביצוע פעולות
- נתונים סטטיסטיים (כמה זמן לקח, כמה שורות נטענו)
- **דוגמאות:**
  - "התחלת הפקת דוח CustomerReport"
  - "נטענו 150 שורות מהפרוצדורה"
  - "דוח הופק בהצלחה תוך 3.5 שניות"

### Warning (לא נרשם ל-DB)
- בעיות לא קריטיות שהמערכת יודעת להתמודד איתן
- נתונים חסרים שיש להם ערך ברירת מחדל
- **דוגמאות:**
  - "לא נמצא שם עברי לשדה CUSTID, משתמש בשם המקורי"
  - "לא נמצא שם לקוד ישוב 999, מציג 'ישוב 999'"
  - "תבנית מכילה placeholder לא מוכר: {{UnknownField}}"

### Error (נרשם ל-DB!)
- שגיאות שמונעות המשך תקין של התהליך
- בעיות שדורשות התערבות או תיקון
- **דוגמאות:**
  - "תבנית CustomerReport.html לא נמצאה"
  - "שגיאת SQL בהרצת פרוצדורה GetCustomerData"
  - "פרמטר חובה 'mnt' חסר"
  - "שגיאה בהמרת HTML ל-PDF"

### Critical (נרשם ל-DB ועוצר את התהליך!)
- שגיאות חמורות שמונעות לחלוטין את פעולת המערכת
- בעיות תשתית קריטיות
- **דוגמאות:**
  - "אין חיבור לבסיס הנתונים"
  - "Chrome לא נמצא במערכת להמרת PDF"
  - "אין הרשאות כתיבה לתיקיית הפלט"
  - "זיכרון המערכת אזל"

## מה נרשם בפועל ל-DB

רק שגיאות מרמת **Error** ומעלה נרשמות לטבלת DBERRORS:

1. **תבניות חסרות או פגומות**
2. **שגיאות SQL ובסיס נתונים**
3. **פרמטרים חסרים או לא תקינים**
4. **כשלים בהמרת PDF/Excel**
5. **בעיות הרשאות**
6. **שגיאות קריטיות של המערכת**

## מה לא נרשם ל-DB

1. **הודעות התקדמות רגילות**
2. **אזהרות על נתונים חסרים עם ערכי ברירת מחדל**
3. **מידע סטטיסטי**
4. **הודעות debug**

## איך לשנות את ההתנהגות

ב-`appsettings.json`:
```json
{
  "ErrorLogging": {
    "DatabaseLogThreshold": "Error",      // רק Error ומעלה ל-DB
    "ProcessBreakThreshold": "Critical",  // רק Critical עוצר את התהליך
    "EnableFileLogging": true,           // גיבוי לקובץ אם DB נכשל
    "EnableConsoleLogging": true,        // הצגה בconsole
    "ConsoleLogThreshold": "Information" // הכל מוצג בconsole
  }
}
```

אם רוצים לרשום גם Warnings ל-DB (לא מומלץ):
```json
"DatabaseLogThreshold": "Warning"
```

אם רוצים שגם Error יעצור את התהליך:
```json
"ProcessBreakThreshold": "Error"
```
